素材标签树结构

与箱包鞋靴使用同一套服饰创意标签语言，内容形式与画面客观要素优先。

内容形式核心：先定义素材的视频创意体裁。
视频结构类型p00标签值：真人口播 / 多人剧情 / 沉浸式产品展示 / 直播切片 / AI数字人口播判断：单人真人讲解或种草=真人口播；两人及以上互动=多人剧情；无人/手部/纯产品=沉浸式。
画面客观要素核心：基于真实画面识别角色和拍摄地点。
拍摄场景类型p00标签值：居家室内 / 纯色棚拍 / 酒店大堂 / 户外街景 / 工厂车间 / 机场 / 商场门店 / 学校展会判断：按画面物理拍摄地直接识别。
出镜角色类型p00标签值：单人女 / 单人男 / 多人对话 / 无人出镜 / 明星判断：按画面人物数量、性别与关系判断；纯产品或仅手部归无人出镜。
商品属性季节、功能与材质构成商品本身的可解释决策点。
适用季节p0标签值：春夏秋冬 / 四季通用 / 开学季 / 暑假出游季 / 换季判断：商品厚薄、画面环境、字幕或口播季节词。
功能属性p0标签值：防滑 / 防水 / 透气 / 显瘦显高 / 增高 / 大容量 / 收纳分层 / 耐磨 / 缓震 / 护脊判断：字幕/口播功能词和实测画面共同确认。
材质属性p0标签值：真皮 / PU / 帆布 / 棉 / EVA / 五金 / 尼龙防泼水判断：画面特写与字幕材质词；无清晰依据不强标。
卖点表达识别素材如何切入需求、建立信任并推动转化。
功能实测p0标签值：弹力 / 防水 / 透气 / 耐磨 / 承重 / 收纳 / 防滑 / 减震判断：测试动作 + 测试字幕或口播。
场景痛点p0标签值：磨脚 / 显胖 / 闷热 / 容量不足 / 收纳乱 / 轮子卡顿判断：痛点文字、前后对比或场景冲突。
信任背书 / 价格促销 / 竞品对比p0标签值：工艺 / 工厂 / 检测 / 达人 / 限时折扣 / 工厂直销 / 平替判断：背书字幕、价格浮层或明确对比话术。
情绪与营销通过情绪、使用场景与风格建立观看动机。
情绪钩子类型p0标签值：身材焦虑 / 大牌平替 / 促销紧迫感 / 美女吸睛 / 亲情关怀 / 猎奇实验判断：开头3秒标题、口播话术、画面情绪。
题材 / 使用场景p0标签值：通勤 / 旅行 / 运动 / 居家 / 礼赠 / 中老年关怀判断：场景背景 + 口播用途综合判定。
穿搭风格 / 节日节点p0标签值：通勤简约 / 休闲日常 / 轻奢高级 / 少女法系 / 运动风 / 开学季 / 618 / 双11判断：整体视觉调性、节点字幕和促销话术。
